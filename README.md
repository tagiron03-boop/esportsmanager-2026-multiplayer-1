# ESM26 Dual Manager

Плагин для Esports Manager 2026: две организации под управлением двух людей
в одном мире, на одном ПК. Переключение управления — по горячей клавише,
без выхода из игры и без правки файлов сохранения.

## Что делает

- **F10** — панель: выбор организаций для менеджера 1 и менеджера 2.
- **F11** — передать ход: управление переходит второму менеджеру.

Обе организации живут в одном мире: общий трансферный рынок, общая турнирная
сетка, ваши команды встречаются между собой. Пока ходит один — вторая
организация ведёт себя как обычная команда мира.

Матчи плагин не трогает: живой матч ведёт тот, чей сейчас ход.

## Требования

- BepInEx 6 IL2CPP, сборка **be.785** (та же, что для GodPanel)
- Esports Manager 2026

## Сборка через GitHub

Терминал не нужен — всё делается через браузер.

1. Создайте новый репозиторий на GitHub (можно приватный).
2. Загрузите в корень: `Plugin.cs`, `ESM26.DualManager.csproj`, `NuGet.config`.
3. Создайте файл `.github/workflows/build.yml` и вставьте туда содержимое `build.yml`.
4. Вкладка **Actions** → workflow **Build Plugin** → **Run workflow**.
5. Когда сборка закончится, скачайте артефакт **ESM26.DualManager** — внутри `ESM26.DualManager.dll`.

## Установка

Положите `ESM26.DualManager.dll` в папку:

```
Esports Manager 2026\BepInEx\plugins\
```

Запустите игру, загрузите карьеру, нажмите **F10**.

## Порядок игры

1. Загрузите карьеру. Нажмите **F10**.
2. «Взять текущую как менеджера 1» — это ваша организация.
3. «Назначить менеджера 2» → выберите организацию друга из списка.
4. Играйте. Когда отыграли свой отрезок — **F11**, управление у друга.

Настройки сохраняются в `BepInEx\config\esm26.dualmanager.slots.txt`,
клавиши меняются в `BepInEx\config\esm26.dualmanager.cfg` (файл появится
после первого запуска).

## Если что-то не работает

Смотрите `BepInEx\LogOutput.log` — плагин пишет туда, что нашёл и что не смог.

Возможные ситуации:

- **Панель не открывается** — плагин не загрузился. Проверьте, что DLL лежит
  в `BepInEx\plugins\` и что версия BepInEx — be.785.
- **«Организации не найдены»** — откройте панель после загрузки карьеры,
  а не в главном меню.
- **Ход не передаётся** — в логе будет причина. Пришлите строки с `DualManager`.

## Замечание

Плагин обращается к игровым объектам через рефлексию, по именам типов и полей.
Если разработчики переименуют внутренние классы в обновлении, плагин перестанет
их находить — тогда потребуется поправить список имён в `GameBridge`.
